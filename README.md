GlowWell Beauty Clinic — Online Appointment Reservation System
A full-stack web application designed to streamline appointment bookings for clients while providing clinic administrators with real-time schedule management, revenue tracking, and automated double-booking prevention.

🌟 Key Features
Client Authentication & RBAC: Secure user registration and login system with Role-Based Access Control distinguishing Customers from Clinic Admins.

Dynamic Appointment Booking: Interactive form allowing clients to choose specialists, beauty treatments, dates, and times with real-time UI validation.

Automated Conflict Prevention Engine: Backend algorithm that checks specialist availability before confirming bookings to prevent double-booking identical time slots.

Admin Dashboard & Analytics: Executive view displaying appointment schedules, total revenue metrics, and booking status controls (Confirm/Cancel).

Responsive RESTful API Design: Asynchronous AJAX communication (fetch API) between the frontend and PHP REST API endpoints for a seamless single-page feel.

🛠️ Technology Stack
Frontend: HTML5, CSS3 (CSS Variables, Flexbox, Mobile Responsive), JavaScript (ES6+, Fetch API, Async/Await)

Backend: PHP 8.x (Procedural & Object-Oriented with PDO)

Database: MySQL / MariaDB (Normalized 3NF Schema)

Environment: Apache / XAMPP / WAMP / phpMyAdmin
